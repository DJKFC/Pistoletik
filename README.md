# Pistoletik

Мобильный рогалик-выживач в духе Vampire Survivors, где главное — **собрать свою безумную пушку** из деталей, плюс предметы в стиле Risk of Rain 2.

## Как скачать
Открой вкладку **Releases → latest** и скачай `Pistoletik.apk`. Каждая отправка в `main` пересобирает APK через GitHub Actions. Новые сборки ставятся поверх старой (ключ подписи постоянный).

## Управление
- Проведи пальцем в любом месте — бег (плавающий джойстик).
- Пушка стреляет сама в ближайшего врага.
- Кнопка справа внизу — оборудование (граната, рывок, купол, чёрная дыра…).
- Пауза — справа вверху: там видно всю сборку пушки, комплекты и предметы.

## Пушка из 5 слотов
| Слот | Что меняет |
|---|---|
| 🔫 Ствол | логику стрельбы: дробовик, луч, спираль, кольцо, орбита, бумеранг, мины, очередь, рельсотрон |
| 💎 Кристалл | стихию и форму пуль: самонаведение-звёзды, осколки, лёд, пустота с притяжением, рост, огонь, молнии |
| 🧵 Обвязка | изолента, резинка (рикошеты), нить судьбы (криты), паутина, щупальце, колючая проволока, провод |
| ⚙️ Механизм | пружина, задний спуск, сервопривод (в стороны), гравидвигатель (разгон), сердце демона |
| 🔸 Патроны | экспансивные, бронебойные, зажигательные, разрывные, плазма, двоящиеся |

Детали бывают **обычные, магические, инопланетные, адские и кибер**. 3 детали одного происхождения дают бонус комплекта, 5 — двойной.

## Остальное
- 26 стакающихся предметов (шприц, электрогитара, ракетница, липкая бомба, тотем бессмертия, бегемот…)
- 6 видов оборудования, 4 героя
- Режиссёр волн с элитными врагами (огненные, ледяные, быстрые, крепкие)
- Боссы каждые 3 минуты: Голем, Королева Улья, Матка Пришельцев
- Сундуки за золото, стаи летучих мышей, рекорды

## Сборка локально
Нужны JDK 17, Android SDK и Gradle 8.9: `gradle assembleRelease`.
